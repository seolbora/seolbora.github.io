# 설보라 아카이브

Personal Archive — In Search of a Name

하나의 링크로 열리는 개인 아카이브 웹앱입니다. 설치 없이 브라우저에서 바로 열리고,
휴대폰에서는 "홈 화면에 추가"로 앱처럼 사용할 수 있어요.

---

## 배포 방법 (GitHub Pages)

### 1. 저장소 만들기

GitHub에 로그인한 뒤 새 저장소를 만듭니다.

- **저장소 이름을 반드시 `seolbora.github.io` 로 지정하세요.**
- Public으로 설정합니다.

> 이 이름으로 만들어야 주소가 `https://seolbora.github.io/` 처럼 짧게 나옵니다.
> 다른 이름(예: `archive`)으로 만들면 주소가 `https://seolbora.github.io/archive/` 가 됩니다.

### 2. 파일 올리기

이 폴더 안의 파일 전부를 저장소 최상단(루트)에 업로드합니다.

```
index.html
manifest.json
sw.js
favicon-64.png
icon-180.png
icon-192.png
icon-512.png
icon-512-maskable.png
README.md
```

웹에서 올리는 경우: 저장소 화면 → `Add file` → `Upload files` →
파일 전부 끌어다 놓기 → `Commit changes`.

### 3. Pages 켜기

저장소 → `Settings` → 왼쪽 메뉴 `Pages` →
`Source` 를 **Deploy from a branch**,
`Branch` 를 **main / (root)** 으로 두고 `Save`.

1~2분 뒤 아래 주소가 열립니다.

```
https://seolbora.github.io/
```

### 4. 프로필에 링크 걸기

`https://github.com/seolbora` 는 GitHub 프로필 페이지라서 그 주소 자체를
아카이브로 바꿀 수는 없습니다. 대신 프로필에서 아카이브로 바로 가도록 연결합니다.

- GitHub 우측 상단 프로필 → `Settings` → `Public profile`
- **Website** 칸에 `https://seolbora.github.io/` 입력 후 저장

그러면 프로필 화면에 클릭 가능한 링크가 뜹니다.

추가로, 저장소 이름을 `seolbora` 로 만들고 `README.md` 를 넣으면
프로필 상단에 소개 카드가 표시됩니다. 거기에 아카이브 링크를 크게 넣어두면
`github.com/seolbora` 에 들어온 사람이 바로 아카이브로 이동할 수 있습니다.

## 앱처럼 설치하기

**아이폰 (Safari)**
공유 버튼 → `홈 화면에 추가`

**안드로이드 / 데스크톱 (Chrome)**
주소창 오른쪽 설치 아이콘 → `설치`,
또는 메뉴 → `앱 설치`

설치하면 주소창 없이 전체 화면으로 열리고, 오프라인에서도 동작합니다.

## 이미지 보드 사용법

- **여러 장 한 번에 추가**: 파일 선택 창에서 사진을 여러 장 선택하면 캡션 없이 바로 전부 보드에 추가됩니다. 한 장만 선택하면 미리보기가 뜨고, 캡션을 적은 뒤 "핀 추가하기"를 눌러야 등록됩니다.
- **여러 장 한 번에 삭제**: 보드 안에서 "여러 장 선택" 버튼을 누르면 사진을 탭해서 여러 개 고를 수 있고, "선택 삭제"로 한 번에 지울 수 있습니다.
- **사진첩/파일에 저장**: 각 사진 오른쪽 아래 ⬇ 버튼(또는 사진을 눌러 크게 본 뒤 "사진 저장하기")을 누르면 기기의 사진첩이나 파일 앱에 저장됩니다.

## 사진 업로드에 대해

사진은 **크기나 화질에 상관없이** 올릴 수 있습니다. 파일을 선택하면 브라우저가
자동으로 적당한 크기(긴 변 최대 1800px, 프로필 사진은 640px)로 줄이고 압축해서
저장합니다. 26MB짜리 고화질 사진도 그대로 올라갑니다.

저장 공간은 IndexedDB를 사용해 수백 MB까지 쓸 수 있어서, 사진을 많이 넣어도
"저장 실패"가 나지 않습니다.

---

## 데이터 저장에 대해

기록·이미지 보드·프로필은 **브라우저 자체에 저장**됩니다.

- 인터넷 연결 없이도 저장되고 열립니다.
- 같은 기기, 같은 브라우저에서만 보입니다. 기기를 바꾸면 내용이 따라오지 않습니다.
- 브라우저 방문 기록/사이트 데이터를 삭제하면 기록도 함께 지워집니다.

중요한 글이나 사진은 별도로 백업해두시길 권합니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `index.html` | 아카이브 본체 (화면·기능 전부 포함) |
| `manifest.json` | 앱 이름·아이콘·테마색 등 설치 정보 |
| `sw.js` | 오프라인 캐시 |
| `icon-*.png`, `favicon-64.png` | 앱 아이콘 (빗속 소녀 그림) |
